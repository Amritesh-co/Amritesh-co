## 👨‍💻 About Me

> I build **AI systems that solve real problems** — from agent orchestration and RAG pipelines to production-ready products running on my own hardware.

I'm a fourth-year Data Science student at **RV College of Engineering** who spends more time in terminals than textbooks. My work sits at the crossroads of **LLM systems**, **backend engineering**, and **self-hosted infrastructure**. I run a 24/7 Ubuntu home-lab server called **Friday** that hosts everything from vector stores and multi-agent frameworks to Nextcloud, Jellyfin, and this portfolio.

**What I care about:**
- 🧠 **Agentic AI & LLM Systems** — multi-agent orchestration, RAG, tool use, structured outputs
- 🚀 **Product Engineering** — turning ideas into working, deployed products fast
- ⚡ **Systems & Infrastructure** — Docker, Nginx, Cloudflare Tunnels, Tailscale, local LLMs
- 📚 **Strong Foundations** — deep DSA practice and algorithmic problem solving
